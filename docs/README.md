## Sparrow Wallet Repository Docs

Note that most documentation for the project can be found at https://sparrowwallet.com/docs/. 
The documentation here is mainly developer-related resources.

That documentation is upstream Sparrow's, and covers this fork wherever the two behave the same,
which is nearly everywhere. It does not describe what this build changes in order to follow the
BLAKE2b chain. For that, see the [README](../README.md).
